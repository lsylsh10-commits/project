# 할 일 관리 앱 PRD

## 1. 프로젝트 개요

### 1.1 프로젝트명
**Todo Management App**

### 1.2 프로젝트 목적
사용자가 하루 동안 해야 할 일을 빠르게 등록하고, 중요도와 날짜를 기준으로 정리하며, 완료 여부를 직관적으로 관리할 수 있는 모바일 중심의 할 일 관리 앱을 개발한다.

복잡한 생산성 도구보다 사용성이 단순하고 직관적인 앱을 목표로 하며, 앱을 실행했을 때 사용자가 가장 먼저 **“오늘 내가 무엇을 해야 하는지”​**를 바로 확인할 수 있도록 한다.

### 1.3 핵심 가치

- 빠른 할 일 등록
- 오늘 해야 할 업무 집중
- 단순하고 직관적인 UI
- 완료 여부를 쉽게 확인
- 일정과 카테고리 기반 정리
- 부담 없이 지속적으로 사용할 수 있는 UX
- 깔끔하면서도 브랜드 아이덴티티가 느껴지는 디자인

---

# 2. 서비스 컨셉

## 2.1 핵심 컨셉

> 오늘 해야 할 일을 빠르게 정리하고, 중요한 일을 놓치지 않도록 도와주는 개인용 할 일 관리 앱

단순한 체크리스트에서 끝나는 것이 아니라 날짜, 중요도, 카테고리, 진행률 등을 활용하여 사용자가 자신의 하루를 쉽게 관리할 수 있도록 한다.

## 2.2 디자인 컨셉

전체적인 UI는 **Toss처럼 여백이 충분하고 정보 위계가 명확한 미니멀 디자인**을 기반으로 한다.

단, 일반적인 블루 계열 생산성 앱과 차별화하기 위해 다음 세 가지 컬러를 브랜드 핵심 컬러로 사용한다.

- Deep Navy
- Gold Yellow
- Alice Blue

전체 화면은 밝고 깨끗하게 유지하되, 딥 네이비를 통해 신뢰감과 고급스러움을 표현하고 옐로우를 포인트 컬러로 활용한다.

### 디자인 키워드

**Clean / Premium / Editorial / Modern / Calm / Productivity**

# 4. 프로젝트 목표

## 4.1 기능 목표

사용자가 다음 행동을 빠르게 수행할 수 있어야 한다.

1. 할 일을 등록한다.
2. 오늘 해야 할 일을 확인한다.
3. 완료 여부를 체크한다.
4. 등록한 할 일을 수정하거나 삭제한다.
5. 날짜별로 할 일을 확인한다.
6. 중요한 할 일을 구분한다.
7. 카테고리별로 할 일을 관리한다.

## 4.2 UX 목표

앱 실행 후 **3초 이내에 오늘 해야 할 일을 파악할 수 있는 구조**를 목표로 한다.

할 일 등록 과정에서도 불필요한 입력을 최소화한다.

### 기본 필수 입력

- 할 일 제목
- 날짜

### 선택 입력

- 시간
- 카테고리
- 중요도
- 메모
- 반복
- 알림

# 7. 진행률

오늘 등록된 할 일의 완료 비율을 표시한다.

```text
5개 중 4개 완료

80%
```

진행률 바의 메인 컬러에는 브랜드 컬러인 **Deep Navy** 또는 보조 블루를 사용한다.

완료 상태에서는 보다 부드러운 Success 컬러를 사용할 수 있다.

---

# 8. 중요 할 일

중요도는 복잡하게 세분화하지 않고 두 단계로 구성한다.

- 일반
- 중요

중요한 할 일에는 **Gold Yellow 컬러의 별 아이콘**을 적용한다.

```text
□ 포트폴리오 제출          ★
```

Gold Yellow는 앱 전체에서 넓은 면적에 사용하지 않고 강조가 필요한 요소에만 제한적으로 사용한다.

---

# 9. 카테고리

기본 카테고리:

- 업무
- 공부
- 개인
- 쇼핑

사용자가 새로운 카테고리를 추가할 수 있도록 확장 가능한 구조로 제작한다.

카테고리는 강한 원색보다 브랜드 컬러에서 파생된 **저채도 컬러**를 사용한다.

# 12. 하단 네비게이션

```text
홈      일정       +      기록      설정
```

### 메뉴

**홈**
오늘 해야 할 일을 확인한다.

**일정**
달력을 확인한다.

**추가**
새로운 할 일을 등록한다.

**기록**
완료한 할 일을 확인한다.

**설정**
앱 설정을 관리한다.

가운데 `+` 버튼은 앱의 Primary Action으로 사용하며 **Deep Navy 배경 + 밝은 아이콘**으로 표현한다.

# 14. UI 디자인 방향

## 14.1 전체 컨셉

전체 UI는 **밝고 깨끗한 화면을 기본으로 하며 넓은 여백과 명확한 타이포그래피를 활용한다.**

카드를 과도하게 사용하거나 모든 영역을 박스로 감싸지 않는다.

필요한 부분에만 카드와 구분선을 사용해 정보 구조를 명확하게 표현한다.

### 핵심 느낌

> Toss의 깔끔함 + Editorial 브랜드의 고급스러운 컬러 감성

# 19. 컬러 사용 비율

화면 전체에서 색상이 과도하게 느껴지지 않도록 아래 비율을 기준으로 한다.

### Neutral / White
**약 70%**

배경, 카드, 여백

### Deep Navy / Blue
**약 20~25%**

버튼, 선택 상태, 제목, 주요 인터랙션

### Gold Yellow
**약 5%**

중요 표시와 강조

### Category / Status Colors
**약 5%**

태그 및 상태 표현

# 30. 최종 디자인 방향

이 앱의 핵심 디자인 방향은

> **깔끔한 생산성 앱에 프리미엄 브랜드 감성을 더하는 것**

이다.

화면 대부분은 White와 Alice Blue 계열의 밝은 색으로 유지하고, **Space Cadet `#192853`을 브랜드의 중심 컬러로 사용한다.**

**Gargoyle Gas `#FFE14E`은 중요한 일정과 핵심 포인트에만 제한적으로 사용하여 브랜드의 개성을 만든다.**

최종적으로 사용자가 앱을 보았을 때

**“깔끔하다 → 쓰기 편해 보인다 → 그런데 색 조합이 예쁘고 기억에 남는다”**

라는 인상을 받을 수 있도록 디자인한다.
