# 모바일 청첩장 웹앱 PRD

## 1. 프로젝트 개요

### 프로젝트명
모바일 웨딩 인비테이션

### 프로젝트 목적
스마트폰 사용자가 링크를 통해 접속하여 신랑·신부의 결혼 소식과 예식 정보를 확인하고, 갤러리·실시간 카운트다운·연락하기·계좌번호 확인·방명록 등의 기능을 사용할 수 있는 모바일 청첩장 웹앱을 제작한다.

단순한 정보 전달형 청첩장이 아니라 **웨딩 화보와 에디토리얼 매거진을 결합한 감성적인 모바일 경험**을 목표로 한다.

---

# 2. 핵심 디자인 콘셉트

## 디자인 키워드

- Editorial Wedding
- Wedding Magazine
- Full Screen Photography
- Romantic
- Modern
- Minimal
- Premium
- Mobile First

## 전체 디자인 방향

첫 화면은 웨딩 사진을 스마트폰 화면 전체에 사용하는 **풀스크린 커버 디자인**으로 구성한다.

사용자가 아래로 스크롤하면 아이보리 계열의 밝은 배경 위에 사진, 타이포그래피, 달력, 초대글, 타임라인, 갤러리 등의 콘텐츠가 자연스럽게 이어지는 **웨딩 매거진형 레이아웃**으로 전환한다.

전체적인 컨셉은 다음과 같다.

**첫 화면 = 영화 포스터**

**스크롤 영역 = 웨딩 매거진**

기능적인 요소는 과도하게 노출하지 않고 버튼, 아코디언, 모달 등을 활용하여 디자인을 해치지 않도록 구성한다.

# 24. 스크롤 등장 애니메이션

본 프로젝트에서는 **스크롤 시 요소가 아래에서 위로 올라오면서 점점 부드럽게 나타나는 동작을 필수 적용한다.**

## 기본 동작

사용자가 화면을 아래로 스크롤하여 각 콘텐츠 영역에 도달하면 해당 요소가 아래쪽에 살짝 위치한 상태에서 시작한다.

스크롤 영역에 진입하면 요소가 **아래에서 위 방향으로 천천히 이동하면서 동시에 투명도가 증가하여 자연스럽게 나타나도록 구현한다.**

동작 예시:

```text
스크롤 전

opacity: 0
translateY: 40px

↓

스크롤 영역 진입

↓

opacity: 1
translateY: 0
```

## 애니메이션 특징

- 아래 → 위 이동
- 서서히 나타나는 Fade In 효과
- 갑작스럽게 등장하지 않도록 부드러운 속도 적용
- 콘텐츠별 약간의 시간차를 적용하여 자연스럽게 노출

## 적용 대상

다음 요소에 기본 적용한다.

- 섹션 제목
- 초대글
- 신랑·신부 정보
- 결혼 날짜
- 카운트다운
- 웨딩 사진
- 타임라인
- 갤러리 이미지
- 예식 정보
- 오시는 길
- 연락하기 버튼
- 계좌번호 영역
- 방명록
- Ending Section

## 권장 애니메이션 값

```css
opacity: 0;
transform: translateY(40px);
transition: opacity 0.8s ease, transform 0.8s ease;
```

활성화 시:

```css
opacity: 1;
transform: translateY(0);
```

## 구현 방식

JavaScript의 `IntersectionObserver`를 사용하여 사용자가 해당 요소를 실제로 스크롤해서 볼 때 애니메이션이 실행되도록 구현한다.

페이지 로딩 시 모든 애니메이션을 동시에 실행하지 않는다.

## 순차 등장 효과

한 섹션에 여러 요소가 있는 경우 동시에 나타나지 않고 약간의 시간 차이를 적용한다.

예:

```text
제목
↓ 0.1초

본문
↓ 0.15초

사진
↓ 0.2초

버튼
```

이를 통해 잡지 페이지를 하나씩 읽어 내려가는 듯한 느낌을 제공한다.

## 주의사항

애니메이션은 과도하게 빠르거나 튀는 동작을 사용하지 않는다.

다음 효과는 기본 디자인에서는 사용하지 않는다.

- Bounce
- 과도한 확대
- 회전
- 빠른 좌우 이동
- 반복 애니메이션

전체적으로 **잔잔하고 고급스럽게 나타나는 움직임**을 유지한다.

# 31. 최종 사용자 경험

사용자가 청첩장에 접속하면 풀스크린 웨딩 사진과 큰 타이포그래피가 먼저 나타난다.

사용자가 아래로 스크롤하면 각 섹션의 제목, 문구, 사진, 버튼 등이 **화면 아래쪽에서 위쪽으로 천천히 올라오면서 동시에 점점 선명해지는 방식으로 등장한다.**

각 요소는 한꺼번에 나타나지 않고 약간의 시간 차이를 두고 순차적으로 등장하여 웨딩 매거진을 한 페이지씩 넘겨 보는 듯한 경험을 제공한다.

전체 애니메이션은 빠르거나 화려한 움직임보다 **잔잔하고 부드럽고 고급스러운 움직임**을 유지한다.

최종적으로 본 프로젝트는 **풀스크린 웨딩 화보 + 에디토리얼 매거진 레이아웃 + 부드러운 스크롤 인터랙션**이 결합된 모바일 청첩장 웹앱을 목표로 한다.
