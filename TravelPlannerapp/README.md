# 국내 여행 일정 + 이동정보 통합 플래너 v4

## 이번 수정 핵심

### 관광 일정
관광 일정 안에서 해당 장소로 가는 간단한 이동정보를 함께 기록합니다.

- 버스: 버스번호 / 승차 정류장 / 하차 정류장 / 간단 메모
- 택시: 출발지 / 목적지 / 간단 메모
- 도보: 출발지 / 목적지 / 간단 메모
- 자차: 출발지 / 목적지 / 간단 메모

관광 일정의 이동정보에는 권장 도착시간, 출발 계산, 교통 알림 같은 복잡한 기능을 넣지 않습니다.

### 장거리 교통편
별도 `장거리 교통편 추가`는 아래처럼 실제 출발시간과 알림이 중요한 이동만 등록합니다.

- 비행기
- 기차
- 고속/시외버스

기존의 권장 도착시간, 권장 출발시간, 사용자 지정 알림 기능은 이 장거리 교통편에만 적용됩니다.
